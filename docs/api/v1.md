# CHIC KIM & MIU API v1 — APP 串接文件

提供給 iOS / Android APP 開發團隊串接 CHIC KIM & MIU 後台的 API 規格。

## 認證模型

採 Bearer JWT token：

1. POST `/api/v1/auth/login` 帶 email + password → 拿 `token`
2. 後續所有 request 帶 header：`Authorization: Bearer <token>`
3. Token 預設有效 7 天（伺服器 `users.auth.tokenExpiration` 控制；登入回應 `expiresIn` 秒數）
4. Token 過期 → 401 → 重新登入

> Web 端用 cookie session；APP 用 token。同一個 user 兩邊可同時登入互不影響。

## Endpoints

### 1. 登入 — `POST /api/v1/auth/login`

**Request**:
```json
{ "email": "user@example.com", "password": "..." }
```

**Response 200**:
```json
{
  "success": true,
  "data": {
    "token": "<JWT>",
    "expiresIn": 604800,
    "user": {
      "id": 123,
      "email": "user@example.com",
      "name": "王小明",
      "phone": "0912xxxxxx",
      "points": 580,
      "shoppingCredit": 250,
      "memberTier": { "id": 3, "slug": "gold", "frontName": "金曜貴公子" },
      "gameTermsAcceptance": { "acceptedVersion": "2026-05-09-v1", "acceptedAt": "..." }
    }
  }
}
```

**Errors**:
- 400 Missing email or password
- 401 Invalid credentials / 帳號已鎖（暴力破解保護）

---

### 2. 註冊 — `POST /api/users/register`

未提供 v1 版（直接用既有 endpoint）。Response 不含 token，需呼叫 login 取得。

```bash
curl -X POST https://chickimmiu.com/api/users/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"...","password":"...","name":"..."}'
```

成功後同 email/password 呼叫 `/api/v1/auth/login` 拿 token。

---

### 3. 會員綜合資訊 — `GET /api/v1/me`

APP 開機/首頁用，一次拿到 user + wallet + 寶物箱摘要 + 遊戲規範狀態。

**Headers**: `Authorization: Bearer <token>`

**Response 200**:
```json
{
  "success": true,
  "data": {
    "user": { ... 完整 profile ... },
    "wallet": { "points": 580, "shoppingCredit": 250, "storedValueBalance": 0 },
    "rewards": {
      "unusedCount": 3,
      "pendingAttachCount": 1,
      "items": [{
        "id": 42,
        "rewardType": "coupon",
        "displayName": "95 折優惠券",
        "couponCode": "MV2025XYZ",
        "state": "unused",
        "expiresAt": "2027-05-09T00:00:00.000Z",
        "requiresPhysicalShipping": false
      }]
    },
    "gameTerms": {
      "enabled": true,
      "currentVersion": "2026-05-09-v1",
      "acceptedVersion": "2026-05-09-v1",
      "requiresAcceptance": false
    }
  }
}
```

**Errors**: 401 Unauthorized

---

### 4. 遊戲狀態 — `GET /api/games`

**Headers**: `Authorization: Bearer <token>`

**Response 200**: 同 web 版（含 `configs / dailyStatus / playerStats / leaderboard / checkinState / termsState`）。

如果 `termsState.requiresAcceptance = true`，APP 應彈出規範 modal 強制簽署。

---

### 5. 同意遊戲規範 — `POST /api/games/accept-terms`

**Headers**: `Authorization: Bearer <token>`

**Request**:
```json
{ "adultConfirmed": true }
```

`adultConfirmed` 在後台 `GameSettings.compliance.requireAdultConfirmation = true` 時為必填。

**Response 200**:
```json
{ "success": true, "data": { "acceptedVersion": "2026-05-09-v1", "acceptedAt": "..." } }
```

**Errors**:
- 400 缺 adultConfirmed（規範要求成年確認）
- 401 Unauthorized

---

### 6. 玩遊戲 — `POST /api/games`

**Headers**: `Authorization: Bearer <token>`

#### 6a. 每日簽到
```json
{ "action": "checkin" }
```

#### 6b. 抽獎（轉盤 / 刮刮樂）
```json
{ "action": "play", "gameType": "spin_wheel" }
{ "action": "play", "gameType": "scratch_card" }
```

刮刮樂 response 加 `cells: ['🎯','🎯','🎯']` 與 `won: true|false` — APP 應顯示三圖示，三同表示中獎。

#### 6c. 電影抽獎
```json
{ "action": "play", "gameType": "movie_lottery" }
```

#### 6d. 穿搭挑戰（fashion_challenge — 兩階段）
```json
// 開始：
{ "action": "play", "gameType": "fashion_challenge" }
// → response 含 challengeId + selectedItems pool

// 提交：
{ "action": "play", "gameType": "fashion_challenge", "subAction": "submit",
  "challengeId": "...", "selectedItems": ["item-1","item-2"] }
```

**Errors**:
- 400 今日次數已達上限 / 點數不足 / 缺欄位
- 403 `requiresTermsAcceptance: true` — 須先 POST accept-terms
- 401 Unauthorized

---

### 7. 寶物箱（UserRewards）讀取與兌換

**讀取**：
```
GET /api/user-rewards?where[user][equals]=<userId>
```
（Payload 內建 collection REST endpoint，access control 限只能看自己的）

**標記已使用（電子券）**：
```
POST /api/user-rewards/consume
{ "rewardId": 42 }
```

實體獎品（`requiresPhysicalShipping: true`）會在會員下次 checkout 時自動 attach 到訂單，無需 APP 主動操作。

---

### 8. 商品 / 訂單

直接用 Payload 內建 collection REST API（同樣支援 Bearer token）：
- `GET /api/products` — 商品列表
- `GET /api/products/<id>` — 商品詳情
- `GET /api/orders?where[user][equals]=<userId>` — 我的訂單
- POST 結帳請依 `/api/checkout` 既有 endpoint

---

## Rate Limiting

目前未強制 rate limit。建議 APP 端：
- `GET /api/v1/me` 不要小於 5 秒呼叫一次
- `POST /api/games` 抽獎按鈕 disable 直到 response 回來
- 後續會視流量加上 server-side rate limit（429 response）

---

## 錯誤回應格式

所有 v1 API 統一：

```json
{ "success": false, "error": "<人類訊息>", "code": "<machine code>" }
```

常見 code：
- `BAD_REQUEST` 400
- `UNAUTHORIZED` 401
- `FORBIDDEN` 403（含 `requiresTermsAcceptance`）
- `NOT_FOUND` 404
- `INTERNAL_ERROR` 500

---

## Deep linking 建議

APP 接收 push notification 時可用以下 deep link：
- `chickimmiu://games` — 遊戲總覽
- `chickimmiu://games/scratch-card` — 刮刮樂
- `chickimmiu://account/treasure` — 寶物箱
- `chickimmiu://orders/<id>` — 訂單詳情

需 APP 端實作 URL scheme + Universal Link / App Link。
