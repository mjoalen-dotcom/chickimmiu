版本 v1.0｜2026-08-14｜狀態：待初始化｜有效期：至 www 切換完成日（日落條款 §6）

## 1. 運作模型：你的詞彙表只剩三個

| 指令 | 效果 |
|---|---|
| **「下一步」** | 授權執行管線的下一個完整步驟：寫碼 → 部署 pre → 跑驗證 → 更新狀態 → 回報。這一個詞就是授權本身，中間不再問你 |
| **「停」** | 緊急煞車。立即中止、狀態標 ⏸、等待指示 |
| **「確認切換www」** | 唯一的終局指令，只在步驟 24 有效 |

三權分立：**執行者** Claude Code（/next）｜**監察者** 每日 09:00 站會（獨立驗 pre 健康與 P0-SEC 迴歸，停滯 ≥2 天置頂提醒）｜**否決者** Alan（下一步／停）。

## 2. 閘型定義

| 閘型 | 意義 | 你要做的事 |
|---|---|---|
| AUTO | 步驟內全自動（含部署 pre、驗證、回滾） | 說「下一步」 |
| INPUT | 有預設值的決策或素材（logo、色票、D1–D4） | 說「下一步」= 接受預設；要改就一句話帶上（例：「下一步，D1 用 SDK」） |
| WAIT | 外部依賴（BP-002 外包合併） | 無。系統只回報缺什麼 |
| 🔒 IRON | 鐵閘：錢、DNS、營運實跑 | 只有這三處需要你動手（§4） |

## 3. 部署授權（寫入 CLAUDE.md，機器可稽核）

- 授權範圍：**僅 pre.chickimmiu.com** —— 含 build、PM2 restart、pre 的 nginx conf（必經 `nginx -t`，失敗即還原）。此授權成立的前提是 www 仍在 Shopline，pre 無真實客流，爆炸半徑 = 內部
- 一律禁止：觸及 www／Shopline／DNS／金流**正式**參數／任何付費（含 CPX32 升級——升級建議以 INPUT 呈報，你一句話核准）
- 每步驟必有**機器可驗證項**；驗證不過，狀態不得推進——這是全自動的真正安全網
- 既有網頁 cart／checkout 檔案：步驟 11（BP-002 合併）前僅外包可動

## 5. 失敗協定（/next 內建，不可繞過）

1. 驗證未過 → 執行該步驟回滾（若有）→ 狀態 🔴 → 停止 → 回報原因
2. 自動重試上限 **1 次**；禁止跳過驗證；禁止帶著紅燈前進
3. 每次「下一步」= 全新 session，只讀 PIPELINE-STATE.md 與對應工作單——15 天管線不靠對話記憶，杜絕 context 漂移
4. 站會偵測異常（站掛、cost 欄位重現）→ 紅燈置頂，管線凍結至你表態

## 6. 日落條款

www 切換完成當日，本規格的部署授權**自動失效**。切換後 pre 的性質從「無客流沙盒」變成「正式站的鏡子」，風險體制不同，運維授權另立文件（AUTOPILOT-002）再議。
