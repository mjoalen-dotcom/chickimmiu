# 行動端人工巡檢清單（FE-QA-001 Prompt I 產出）

目標：pre.chickimmiu.com，實機或 Chrome 行動模擬皆可。10 項內，涵蓋導覽／篩選／加購／結帳入口／圖片輪播。

1. **首頁 → 商品頁**：從首頁點一張商品卡進商品頁，圖片、價格、庫存狀態正確顯示，無版面跳動（CLS）。
2. **商品列表篩選／排序**：`/products` 切換分類、價格區間、排序（新品／熱銷／價格），URL 隨篩選更新且分頁正確（server-side pagination，非 load-all）。
3. **商品圖片輪播**：商品頁滑動／點擊切換圖片，手勢流暢、無圖片閃爍或錯位。
4. **加入購物車**：商品頁選規格（顏色／尺寸）後加入購物車，購物車 icon 數字即時更新，無需重新整理。
5. **購物車 → 結帳入口**：購物車頁「前往結帳」按鈕可點擊並正確導向 `/checkout`，金額（含運費／折扣）與購物車一致。
6. **導覽選單（漢堡選單）**：手機版導覽開合順暢，各分類連結可正常跳轉，選單開啟時背景不可捲動。
7. **登入／會員中心**：登入後可進入 `/account`，會員資訊與訂單記錄正確載入。
8. **部落格文章頁**：`/blog/[slug]` 文章內容、圖片正常渲染，不因文章來源站別（購物網站／金老佛爺）而讀不到。
9. **404 情境**：手動輸入不存在的網址，確認顯示品牌化 404 頁且「回首頁」「探索商品」按鈕可點擊。
10. **FloatingQuickMenu／遊戲入口**：右下角浮動選單可展開，「遊戲」連結可正常進入 `/games` 且不影響其他頁面操作（如結帳流程）浮動不遮擋按鈕。

## 巡檢方式

- 可由 Alan 親自用手機開啟 pre.chickimmiu.com 逐項點過一輪；或委託 Chrome 巡站協作（Browser pane 行動模擬 375×812），但需注意 MCP content script 可能造成 hydration 假象（[[feedback_chrome_extension_hydration_artifact]]），發現異常時建議先在真實瀏覽器覆核一次再回報。
- 本清單不含金流／發票／DNS 等 IRON 閘項目，那些由 AUTOPILOT 後續步驟另行處理。
