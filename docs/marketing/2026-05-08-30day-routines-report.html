HOW TO OPERATE
操作指南
啟動後 routines 自動跑 · 你只需要管理 3 件事

1 看每日產出

Routines 會把 markdown commit 到你的 GitHub repo main branch。直接去看：

  • docs/standups/ — 每日早晨 standup
  • docs/recaps/ — 每日晚間 recap
  • docs/weekly/ — 週一 plan / 週五 review
  • docs/ROADMAP_30D.md — 30 天計畫總覽

首次跑（2026-05-11 週一）會自動建立 ROADMAP_30D.md。

2 暫停 / 修改 / 立即跑

兩種方式：

  • Web UI：claude.ai/code/routines（可暫停、改 cron、Run now、刪除）
  • 跟我講：「列出 routines」/「暫停 X」/「立刻跑 Y」/「把 X 改成 19:00」

注意：routines 無法用 CLI 刪除，只能在 web UI 刪。

3 Push 權限設定

Routines 跑完會試 git push origin main。預設只有 read 權限可能會卡。

  • 裝 Claude Code GitHub App 到 chickimmiu repo
  • 授予 contents: write 權限
  • 下週一第一次跑時看 routine 詳情頁的 logs
  • 如果還是失敗，跟我講改 PR 模式

4 30 天後處理

計畫跑完（約 2026-06-08 前後）：

  • 暫停 4 個 routines（不要刪，保留 prompt 模板）
  • 更新 ROADMAP_30D.md 為下個 30/60 天計畫
  • 重新啟用 routines，prompt 會自動讀新計畫
  • 或者決定不需要每日 standup 直接刪除
