# /next — CKMU 切換管線推進器（AUTOPILOT-001）

使用者說「下一步」或執行本指令時，嚴格依下列程序執行：

## 程序

1. **定位**：讀 `docs/workorders/PIPELINE-STATE.md`，找到第一個狀態非 ✅ 的步驟。將其標 🔵 並 commit（宣告佔用，避免多 session 撞車）。

2. **閘檢**：
   - ⏳WAIT 且外部條件未滿足 → 只回報「缺什麼、如何確認」，不執行，狀態還原 ⚪。
   - 🔒IRON → 不執行任何動作。輸出該步驟的操作清單與驗證方式，等待 Alan 親自完成；步驟 24 必須收到原文「確認切換www」才可協助產出切換指令（仍由 Alan 執行）。
   - INPUT 且本次訊息未附素材／決策 → 採用工作單載明之預設值，並在回報中明確標註「本步驟採預設：____」。

3. **執行**：讀取該步驟「依據」欄指向的工作單 Prompt **全文**，完整執行——含寫碼、commit、部署至 pre（僅限 pre；`nginx` 修改必經 `nginx -t`，失敗即還原）、執行「機器驗證項」。

4. **驗證分流**：
   - 通過 → 更新 STATE（✅、完成日、產出路徑）、必要時追記決策紀錄區、commit。
   - 未過 → 執行該步驟回滾（若工作單有定義）→ 狀態 🔴 → **停止**。重試上限 1 次；禁止跳過驗證；禁止推進下一步。

5. **回報**（固定格式，10 行內）：

```
[完成] 步驟 NN：名稱
[驗證] 指令與結果（原樣貼）
[產出] 檔案路徑 / 截圖路徑
[採用預設] （若 INPUT 步驟）
[下一步預告] 步驟 NN+1：名稱｜閘型｜需要 Alan 準備：____（無則寫「說下一步即可」）
```

## 鐵律

- 每次執行為**獨立 session**：不依賴先前對話記憶，一切以 STATE 檔與工作單為準。
- 全程遵守 CLAUDE.md 之 AUTOPILOT 段落：部署僅限 pre；觸及 www／Shopline／DNS／正式金流／任何付費 → 停止並報告。
- 步驟 11 之前不碰既有網頁 cart／checkout 檔案（BP-002 外包領域）。
- 使用者說「停」→ 立即中止，當前步驟標 ⏸，回報中止點與安全狀態。
- 開工讀 `AI-INBOX.md` 與 `AI-CONTEXT.md`；完工 `ai-report` 回報（CHICMIU-5090 協定）。
